RL for Autograding Adjustment

An study on algorithm course dataset

ITCS 6114 · Fall 2025 dataset

The grading bottleneck

An AI grader assigns scores to student algorithm submissions.

A TA reviews every AI score and adjusts where the AI was wrong.

Question: can a model learn to predict which submissions need adjustment — and reduce the TA’s review burden?

Frame as a learned correction policy

For each submission, predict one of 5 actions:

Trust AI (0) +1 point +2 points +3 points Flag for human review

Goal — match the TA’s actual adjustment.

Features the agent sees

Each submission becomes a 16-dimensional vector:

  • AI score (normalized 0–1)
  • 13-dim one-hot for question ID
  • Response length (normalized)
  • AI feedback length (normalized)

          

        

      


      
      

        

          
Reward shaping

          

            Reward depends on how close the predicted adjustment is to the actual TA adjustment,
            with a separate bonus for correctly flagging large adjustments.

What the result tells us

          
    
            
  1. For tabular, one-step decision problems with small feature sets, a properly-tuned classifier outperforms PPO on raw accuracy.
    2. 
            
  2. The RL framing’s value is in expressive action spaces (the flag action) and reward shaping — not in raw prediction.
    3. 
            
  3. RL is more likely to win when problems become sequential — multi-step grading sessions, longitudinal student tracking, or adaptive question selection.
    4.
