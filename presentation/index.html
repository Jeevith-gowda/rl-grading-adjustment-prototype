Prototype

RL Grading Adjustment Prototype

Predicting TA grade adjustments on AI-graded student submissions

Built on Professor Cheng’s autograding dataset

The problem

Professor Cheng has an AI grader that scores student submissions automatically.

A TA reviews every AI grade and adjusts it where needed.

Question: can reinforcement learning learn which submissions need adjustment — and by how much?

The data

  • 1,520 total student submissions in the updated dataset
  • 1,317 used after filtering out question 9 (different scoring scale)
  • Each submission includes: AI score (0–10), TA final grade (0–10), question text, response text, AI feedback
  • 80/20 train/test split — 1,054 train / 263 test

What I built

  • Custom Gymnasium environment (GradingAdjustmentEnv)
  • PPO agent trained for 50,000 timesteps
  • 5 discrete actions: trust AI, +1, +2, +3, or flag for human review
  • State features: AI score, one-hot question ID, response length, feedback length
  • Reward: +10 if within 0.5 of true adjustment, +5 within 1.0, −5 if off by 2+ (plus bonus for correct flagging on large adjustments)

Key finding

The AI is systematically harsh on complex algorithmic questions

Knapsack, BFS/DFS, MST / shortest paths — the TA consistently adds +2 to +3 points back. The agent picked up this pattern without hand-coded rules.

Limitations

  • Small dataset (1,317 examples)
  • Simple feature set — no rubric criteria, no text embeddings
  • Discrete actions only (no fractional adjustments)
  • Single course, single semester

Next steps

  • Add rubric-level features
  • Try response embeddings (e.g. sentence-transformers)
  • Finer action space (negative adjustments, half-point bins)
  • Compare against offline RL / behavior cloning
