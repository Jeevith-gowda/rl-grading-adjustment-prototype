What this isn’t

  • Small dataset (1,317 examples)
  • No text embeddings
  • Discrete actions only
  • Single course, single semester

Where I’d go next

  1. Add text embeddings of student response and AI feedback
  2. Expand action space (negative adjustments, half-points)
  3. Try sequential framing (track student progress over time)
